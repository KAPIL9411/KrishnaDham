## 🔧 **Using CoordinatePicker:**

### **Step-by-Step:**

1. **Open Tool:**
```
http://localhost:5173/coordinate-picker
```

2. **For Each Zone:**
   - Enter: "Zone 1 - Top Left Corner"
   - Click 4 corners (clockwise from top-left)
   - Verify polygon looks correct
   - Click "Save Zone"

3. **Zone 9 Special:**
   - Enter: "Zone 9 - Main Road Frontage"
   - Click 4-5 points following the diagonal road
   - Start from top-left, go clockwise
   - Save

4. **Export:**
   - After all 9 zones mapped
   - Click "Export All Zones"
   - Save JSON file

---

## 📝 **Coordinate Format:**

Each zone will have coordinates like:
```
"100,50 400,50 400,300 100,300"
```

This means:
- Point 1: (100, 50) - Top-left
- Point 2: (400, 50) - Top-right
- Point 3: (400, 300) - Bottom-right
- Point 4: (100, 300) - Bottom-left
