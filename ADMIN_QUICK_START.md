# ⚡ Admin Panel - Quick Start (5 मिनट)

## 🎯 Admin Panel Access करने के 3 Simple Steps

---

## Step 1: Firebase में Admin User बनाएं (3 मिनट)

### 1. Firebase Console खोलें:
```
https://console.firebase.google.com
```

### 2. Project Select करें:
```
"krishnadham-a4789" पर click करें
```

### 3. Authentication Setup करें:
```
Left sidebar → "Authentication" → "Get Started"
```

### 4. Email/Password Enable करें:
```
"Sign-in method" tab → "Email/Password" → Enable → Save
```

### 5. Admin User बनाएं:
```
"Users" tab → "Add User"

Email: admin@shreekrishnadham.in
Password: (अपना strong password)

"Add User" पर click करें
```

✅ **Done!** User बन गया!

## 🔧 अगर Login नहीं हो रहा?

### Check करें:

1. **Firebase में user बना है?**
   ```
   Firebase Console → Authentication → Users
   admin@shreekrishnadham.in दिखना चाहिए
   ```

2. **Email/Password correct है?**
   ```
   Email: admin@shreekrishnadham.in
   Password: वही जो Firebase में set किया
   ```

3. **Internet connection है?**
   ```
   Firebase connection के लिए internet चाहिए
   ```

4. **Browser console में error?**
   ```
   F12 press करें → Console tab check करें
   ```
