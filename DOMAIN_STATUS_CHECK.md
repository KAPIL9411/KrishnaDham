## 🧪 Testing Commands (Technical)

### Check Nameservers:
```bash
# Mac/Linux Terminal:
dig NS shreekrishnadham.in

# Windows Command Prompt:
nslookup -type=NS shreekrishnadham.in

# Expected Output:
ns1.vercel-dns.com
ns2.vercel-dns.com
```

### Check A Record (after propagation):
```bash
dig A shreekrishnadham.in

# Should show Vercel's IP:
76.76.21.21
```

### Check Website Response:
```bash
curl -I https://shreekrishnadham.in
```
