# 🌐 Domain Setup - आसान तरीका (हिंदी में)

## 🎯 Goal: shreekrishnadham.in को Vercel से connect करना

---

## ⚡ सबसे आसान तरीका (10 मिनट)

### **Step 1: Vercel में जाएं** (2 मिनट)

1. खोलें: https://vercel.com
2. अपनी project (KrishnaDham) पर click करें
3. ऊपर **"Settings"** tab पर click करें
4. बाएं side में **"Domains"** पर click करें
5. **"Add Domain"** button पर click करें
6. Type करें: `shreekrishnadham.in`
7. **"Add"** पर click करें

✅ Vercel आपको 2 nameservers दिखाएगा:
```
ns1.vercel-dns.com
ns2.vercel-dns.com
```

**इन्हें copy कर लें!** 📋

---

### **Step 2: GoDaddy में जाएं** (5 मिनट)

1. खोलें: https://www.godaddy.com
2. Login करें
3. ऊपर **"My Products"** पर click करें
4. **"Domains"** section में जाएं
5. `shreekrishnadham.in` के सामने **"DNS"** button पर click करें

---

### **Step 3: Nameservers Change करें** (3 मिनट)

1. नीचे scroll करें **"Nameservers"** section तक
2. **"Change"** button पर click करें
3. **"Enter my own nameservers"** select करें
4. पुराने nameservers **delete** करें
5. नए nameservers add करें:
   - First: `ns1.vercel-dns.com`
   - Second: `ns2.vercel-dns.com`
6. **"Save"** button पर click करें

✅ **Done!** 🎉

---

## ⏳ अब क्या होगा?

### तुरंत (0-5 मिनट):
- GoDaddy में changes save हो जाएंगे

## 🐛 अगर Problem आए तो

### Problem 1: Domain नहीं खुल रहा
**Solution:**
- 1-2 घंटे wait करें (DNS propagation time)
- Browser cache clear करें (Ctrl+Shift+Delete)
- Mobile data से try करें (WiFi की बजाय)

### Problem 2: "Invalid Configuration" दिख रहा है
**Solution:**
- Nameservers फिर से check करें
- Spelling mistakes check करें
- 10 मिनट wait करें

### Problem 3: SSL Error आ रहा है
**Solution:**
- 30 मिनट wait करें (SSL certificate issue होने में time लगता है)
- Vercel में जाकर "Refresh SSL Certificate" करें

### Problem 4: www नहीं खुल रहा
**Solution:**
- Vercel में `www.shreekrishnadham.in` भी add करें
- Same nameservers use होंगे
- 10 मिनट wait करें
