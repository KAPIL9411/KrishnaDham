## 🎯 Setup Steps (Do Now)

### In Vercel:
- [ ] Login to Vercel
- [ ] Go to project Settings
- [ ] Click on Domains
- [ ] Add domain: shreekrishnadham.in
- [ ] Add domain: www.shreekrishnadham.in
- [ ] Copy nameservers:
  - [ ] ns1.vercel-dns.com
  - [ ] ns2.vercel-dns.com

### In GoDaddy:
- [ ] Login to GoDaddy
- [ ] Go to My Products → Domains
- [ ] Click DNS for shreekrishnadham.in
- [ ] Find Nameservers section
- [ ] Click Change
- [ ] Select "Enter my own nameservers"
- [ ] Delete old nameservers
- [ ] Add: ns1.vercel-dns.com
- [ ] Add: ns2.vercel-dns.com
- [ ] Click Save
